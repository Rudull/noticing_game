## Roadmap

The following roadmap outlines planned features and improvements for Noticing Game:

### Completed / In Beta

- [x] **User Auth & Sync:** Synchronization of settings, streaks, and progress across devices.
- [x] **Multi-Platform Support:** Fully functional on **Netflix** and **Disney+** in addition to YouTube.
- [x] **Listening Mode (Blur):** One-click button to blur subtitles for dedicated listening practice.
- [x] **Manual Backups:** Export and import your data manually (JSON) for local safe keeping.
- [x] **Interactive Heatmap:** Github-style activity tracking with daily streaks.
- [x] **Smart Fallback (Emergency Mode):** Extract subtitles directly from the page when backend is offline.
- [x] **Anki Integration:** Refined export/import with Anki.
- [x] **Phrasal Verb Detection:** Support for multi-word expressions.
- [x] **Backend Auto-Updates:** Mechanism to keep the backend executable up to date.

### Short Term

- [ ] **UI Localization:** Translate the extension interface into multiple languages.
- [ ] **Expanded Language Support:** Add support for Mandarin, German, Japanese, and more.
- [ ] **Multi-list Selection:** Ability to select and play with multiple word lists simultaneously.
- [ ] **Irregular Word Detection:** automatically map irregular forms (e.g., "went") to their base forms (e.g., "go").
- [ ] **One-click backend installer:** Simplify backend setup for non-technical users.
- [ ] **Community word lists:** Allow users to share and import lists from a central repository.
- [ ] **Report Issues & Ideas:** Enable reporting of problems and feature ideas from both the Add‑on and the local server to GitHub.
- [ ] **Refactor Local Server:** Separate responsibilities in the local server code for better maintainability.
- [ ] **MacOS Backend Compilation:** Implement and test the backend compilation and distribution for MacOS, ensuring feature parity with Windows and Linux.


### Medium Term

- [ ] **Mobile browser support:** Explore support for mobile Chrome/Edge/Firefox.
- [ ] **Cloud backend option:** Optional hosted backend for users who can't run a local server.
- [ ] **Advanced analytics:** Visualize vocabulary growth and learning patterns beyond simple consistency.

### Long Term

- [ ] **Gamification:** Badges, leaderboards, and social features.
- [ ] **AI-powered suggestions:** Personalized word recommendations based on user progress.
- [ ] **Full Multi-Platform Support:** Native apps or broader browser support.
